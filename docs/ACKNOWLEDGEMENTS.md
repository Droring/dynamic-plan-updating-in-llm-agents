# Upstream benchmark and attribution

This pilot builds on CostBench's benchmark environment, tool definitions, task and state abstractions, and saved or derived materials. The official upstream repository is [JiayuJeff/CostBench](https://github.com/JiayuJeff/CostBench). The conference paper appeared in ACL 2026: [ACL Anthology](https://aclanthology.org/2026.acl-long.584/); [arXiv preprint](https://arxiv.org/abs/2511.02734).
