# Archived Model-Evaluation Records

This directory preserves earlier provider responses, usage metadata, ledgers and scores associated with source tasks. These are historical records from an earlier evaluation protocol, not the current 50-task benchmark results.

Use `experiments/paired_50/live_results/deepseek-flash/` for the canonical structured decision results and `experiments/paired_50/native_execution/` for native execution results. The archived response records are retained for provenance and should not be pooled with current scores.
