# Source Records

This directory contains the immutable source material used to build the canonical 50-task CostBench benchmark.

The **45 source tasks are now represented by one merged registry** in [`source_archive/source_pairs.json`](source_archive/source_pairs.json). Five additional tasks are generated by the canonical extension builder under `experiments/paired_50/generated/pairs.json`. The current benchmark is therefore one 50-task dataset with 100 matched conditions, not two separately reported cohorts.

The archive retains the original fixture files, request/response records, hashes and historical evaluation outputs under `source_archive/` for provenance. Those records document how the source material was produced; they are not separate active experiments or current evaluation results.

Use the [canonical 50-task study](../../README.md), its [single builder](../../build_unified_dataset.py), and the frozen [50-task registry](../../generated/task_registry_50.json) for current research and reproduction. Do not edit original raw responses or hashes.
