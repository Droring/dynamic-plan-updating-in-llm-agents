# Mechanism diagnosis

Separate possible failure stages after new environment facts arrive: (1) new fact not observed; (2) dependent old evidence/intermediate artifacts not invalidated; (3) alternatives not generated/evaluated; (4) final decision conflicts with evidence already available; (5) correct decision but failed tool action/recovery.

Current evidence consists of repeated probes on reused development tasks and selected native execution traces. These are mechanism-discrimination experiments, not independent task prevalence estimates.

See [mechanism evidence ladder](../../research/plan_commitment_pilot/RESEARCH_MAINLINE.md).

**Attribution rule:** Model explanations are not ground truth about internal cognition. Attribute only observable behavior from prompts, observations, state snapshots, tool arguments and outcomes. Oracle-supplied alternatives are diagnostic interventions, not deployable methods.

Formal live plan-commitment claims require at least 20 independent eligible tasks (target 30), Agent-authored prospective plans, executed prefixes, same-state matched semantic updates, and an independent updated-goal verifier.
