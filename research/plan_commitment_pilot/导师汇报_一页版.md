# 导师阅读版｜LLM Agent 动态计划更新失误研究

**科研训练阶段汇报｜统一 50 任务配对研究与 CostBench 原生执行审计**

## 一、研究动机

我本科具有自动化与控制工程背景，毕业设计涉及动态环境中的路径规划与重规划。因此，我希望研究 LLM Agent 在多步工具执行过程中，面对新的环境事实时，能否及时更新原计划。

核心不是让 Agent 一遇到变化就 SWITCH，而是判断原计划是否仍然有效：有效时 RETAIN，局部依赖受影响时 REPAIR，原方案失效时 SWITCH。

## 二、核心实验：统一 50 个独立任务

当前正式配对研究统一为 **50 个独立 CostBench 基础任务、100 个匹配条件**。每个任务具有同一 checkpoint 下的 RETAIN 与 SWITCH 条件，五个任务类别各 10 个。

DeepSeek Flash 结构化决策结果：

| 指标 | 结果 |
|---|---:|
| RETAIN 准确率 | 48/50（96%） |
| SWITCH 准确率 | 3/50（6%） |
| 配对准确率 | 1/50（2%） |
| 平衡准确率 | 51% |

同一批 50 个任务还完成了 100 条 CostBench 原生工具执行轨迹：

| 指标 | 结果 |
|---|---:|
| RETAIN 首步行动准确率 | 48/50（96%） |
| SWITCH 首步行动准确率 | 2/50（4%） |
| 配对首步准确率 | 1/50（2%） |
| 两个条件下首步决策相同 | 48/50（96%） |
| 到达目标状态 | 100/100 |

两种协议分别测量结构化标签和真实工具首步行动，不能混为一个准确率。全部轨迹到达目标，也不代表 Agent 正确更新了计划：在 48/50 组配对任务中，两个条件的首步决策相同。

需要说明，配对研究中的 incumbent suffix 由求解器构造并提供给 Agent，实验测量的是受控 checkpoint 下的决策和可观察行动，不是 Agent 自主形成旧计划后的承诺效应。

## 三、其他独立证据

1. **官方 CostBench 原生动态鲁棒性审计：**80 个任务（其中 Query00499 与 50 任务配对研究重合），静态环境通过 70/80，动态环境通过 60/80；13 个任务从静态正确变为动态错误，3 个反向变化。这说明动态环境下存在鲁棒性下降，但不能把所有下降都归因于错误保留计划。
2. **计划承诺与证据门控审计：**80 个候选中得到 67 个可回放事件检查点，解析出 27 份真实前瞻计划。这是独立审计，不与 50 个配对任务相加。
3. **机制诊断：**研究新事实观察、旧证据失效、备选方案评估、决策一致性和后续动作恢复之间的失配。
4. **方法原型：**实现 Evidence-Dependency Refresh（EDR）和 Action Guard。现有四任务开发试验未证明它们优于简单明确的新旧事实更新提示，因此暂不将其宣称为有效新算法。

## 四、目前最可靠的结论

在当前受控的 50 任务配对实验中，DeepSeek Flash 对 SWITCH 条件的识别明显弱于 RETAIN；原生执行中也观察到首步行动对配对环境变化不敏感。官方 80 任务审计进一步显示动态执行的最终答案鲁棒性下降。

这些结果支持继续研究环境事实如何传播到计划决策与工具行动，但尚未证明所有失败都来自 Agent 对自己计划的承诺，也尚未得到经过独立验证、优于简单事实更新基线的新算法。

## 五、希望导师指导的问题

是否值得进一步研究“基于状态与证据一致性的动态计划更新”？下一阶段应优先建立足够数量的、具有真实 Agent 前瞻计划、同状态配对事件和独立语义判分器的任务，再进行方法比较。
