# CostBench Candidate Source Registry

This directory preserves the frozen source selection of 200 structurally distinct CostBench candidate task IDs. Its original 25/50/125 allocation is retained as selection provenance; it is not the allocation used by the official 80-task native study.

This is a candidate-selection record, not 200 completed Agent evaluations or a model-training dataset. The run-organization allocation used for the official native baseline is documented in the [official native task allocation](../official_native_task_allocation/README.md).

The original candidate IDs and source hashes are preserved for provenance. They should not be described as the primary 50-task paired benchmark; that benchmark has its own canonical registry under `experiments/paired_50/`.
